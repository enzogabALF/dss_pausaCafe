# Feature Spec - Pausa Cafe DSS Demo

## Scope
Implement the validated backlog for the Pausa Cafe DSS demo on Next.js 15 + TypeScript + Tailwind with optional PostgreSQL + Prisma persistence.

## Core goals
- Keep the simulation, KPI dashboard, analytics, alerts, and export flows working.
- Add the missing backlog items identified during validation.
- Preserve the MVP demo mode without requiring a database.

## Pending backlog
- Authentication and role-based access
- Saved simulation scenarios (save, edit, reuse)
- Inventory and staff operational data
- Real alerts from KPI and stock thresholds
- Report history and export metadata
- Non-functional validation for performance, concurrency, browser compatibility, reliability, and availability
